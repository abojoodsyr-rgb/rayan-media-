# Rayantube — تطبيق أندرويد

تطبيق أندرويد (Kotlin + Jetpack Compose) بهوية "Rayantube": شاشة رئيسية للصق رابط،
مكتبة تنزيلات محلية، مشغل فيديو داخلي، وإعدادات (وضع ليلي / مسح الكاش).

## نطاق التطبيق — مهم قبل ما تبدأ

يعمل Rayantube على **تنزيل روابط ملفات فيديو مباشرة فقط** (رابط ينتهي بامتداد
فيديو مثل `.mp4` أو `.webm`، أو رابط من تخزينك السحابي الخاص، أو أي مصدر فيديو
تملك حقوقه أو صلاحية الوصول إليه).

**لا يحتوي المشروع على أي كود لاستخراج الفيديوهات من صفحات يوتيوب أو إنستقرام
أو تيك توك أو فيسبوك.** هذا غير مدرج عمدًا: تلك المنصات تمنع صراحة في شروط
استخدامها استخراج/تنزيل الفيديو من صفحاتها بأي أداة خارجية، سواء للاستخدام
الشخصي أو غيره. `DownloadHelper.kt` يستخدم `DownloadManager` الرسمي في أندرويد
لأي رابط HTTP/HTTPS مباشر — تمامًا مثل أي متصفح أو مدير تنزيلات عادي.

إذا كان عندك مصدر فيديو مرخّص فعليًا (خادمك الخاص، تخزين سحابي، محتوى
Creative Commons بروابط مباشرة)، وصّله بحقل الرابط في الشاشة الرئيسية وراح يشتغل مباشرة.

## المتطلبات

- Android Studio (Koala أو أحدث يُفضّل)
- JDK 17
- Android SDK 34 (سيطلبه Android Studio تلقائيًا عند الفتح)

## طريقة التشغيل

1. افتح Android Studio → **Open** → اختر مجلد `RayanTube` هذا.
2. خلي Android Studio يعمل Gradle Sync تلقائيًا (بيحمّل نسخة Gradle المطلوبة
   بنفسه حسب `gradle-wrapper.properties`، ما تحتاج تسوي شي يدوي).
3. شغّل التطبيق على محاكي أو جهاز حقيقي (زر ▶ Run).

## هيكلية المشروع

```
app/src/main/java/com/rayan/rayantube/
├── MainActivity.kt              نقطة الدخول + Scaffold + التنقل السفلي
├── navigation/NavGraph.kt        مسارات الشاشات (الرئيسية / التنزيلات / المشغّل / الإعدادات)
├── ui/theme/                     ألوان وخطوط الهوية (أحمر C0392B / كحلي 16213E)
├── ui/screens/
│   ├── HomeScreen.kt             حقل الرابط + زر التنزيل
│   ├── DownloadsScreen.kt        قائمة الفيديوهات المحفوظة (MediaStore) + صور مصغّرة
│   ├── PlayerScreen.kt           مشغّل ExoPlayer داخلي
│   └── SettingsScreen.kt         الوضع الليلي، مسح الكاش، عن التطبيق
├── ui/components/RayantubeBottomBar.kt
└── data/
    ├── DownloadHelper.kt         يستخدم DownloadManager الرسمي (روابط مباشرة فقط)
    ├── DownloadReceiver.kt       يستقبل إشعار اكتمال التنزيل
    ├── VideoRepository.kt        يقرأ الفيديوهات المحفوظة عبر MediaStore
    ├── VideoItem.kt              نموذج بيانات الفيديو
    └── ThumbnailImageLoader.kt   Coil + استخراج إطار مصغّر من الفيديو محليًا
```

## التخصيص

- **الألوان/الأيقونة**: `ui/theme/Color.kt` وملفات `res/mipmap-*` (تم توليدها من
  نفس ملفات SVG لهوية Rayantube).
- **إضافة مصدر تنزيل شرعي آخر**: عدّل `DownloadHelper.enqueueDirectUrlDownload`
  لو تبي تتحقق من نطاق/دومين معيّن قبل السماح بالتنزيل (مثلاً لو تبي تقصره على
  خادمك الخاص فقط).
- **صلاحيات التخزين**: المشروع مهيأ لـ Scoped Storage (أندرويد 10+) عبر
  `DownloadManager` + `MediaStore`، ما يحتاج صلاحيات تخزين إضافية على الأجهزة
  الحديثة.
